# AI Study Test Pack

Upload the three source files in this folder as separate courses or as separate
documents in one practice course. They are intentionally small, text-based,
and structured for predictable citation testing.

## Files

- `Ecology Energy Flow Notes.txt` tests UTF-8 text parsing and `#` headings.
- `Cell Biology Study Notes.docx` tests Word heading extraction and organelle questions.
- `Forces and Motion Lab Brief.pdf` tests selectable PDF text and page citations.

## Suggested Tutor Prompts

Select only the related source before asking each question.

- Cell Biology: `What part of the cell releases usable energy from food?`
- Cell Biology: `I think mitochondria make food from sunlight. Is that right?`
- Ecology: `Why is less usable energy available at higher trophic levels?`
- Ecology: `How are energy flow and matter cycles different?`
- Forces PDF: `Why does a 2 kg cart accelerate at 3 m/s² when the net force is 6 N?`
- Forces PDF: `What variable was controlled in the cart investigation?`
- No matching source: select Cell Biology and ask `What is quantum entanglement?` to confirm the honest general-knowledge label.

## Suggested Assessment Tests

- Create a five-question foundational multiple-choice test from Cell Biology with the topic `cell organelles`.
- Create a five-question standard worksheet from Ecology with the topic `energy flow and decomposers`.
- Create a three-question challenge worksheet from the Forces PDF with the topic `net force and acceleration`.

For each assessment, check that every question has a citation, edit one prompt
or answer, save it, reopen it, and print both the student copy and answer key.
